# Семантическое сопоставление

SitePack 1.2 проверяет межплатформенный перенос через канонический слой:

```text
адаптер источника -> семантический профиль -> рецепт -> возможности цели
                  -> план преобразования + отчёт совместимости
```

Стандарт не хранит отдельную матрицу для каждой пары CMS. Семантический профиль
описывает переносимые сущности, поля, связи и файлы. Рецепт задаёт направленное
декларативное сопоставление. Целевой адаптер сообщает фактически поддерживаемые
им возможности.

Рецепт не может содержать PHP, JavaScript, SQL, shell-команды, произвольные
выражения или другой исполняемый код. Неизвестная необязательная операция
пропускается с предупреждением, а неизвестная обязательная операция блокирует
планирование.

Отчёт совместимости делит данные на точно переносимые, преобразуемые,
сохраняемые через fallback, пропускаемые и блокирующие. В отчёте отдельно
фиксируются потери представления, содержимого, поведения и безопасности. Сам
отчёт не разрешает импорт и не изменяет целевую систему.

Архив может одновременно содержать raw-слой платформы для точного восстановления
в ту же систему и переносимый семантический слой. Подпись подтверждает
неизменность встроенного рецепта, но не делает его доверенным. Возможности
целевой системы всегда предоставляет локально установленный импортёр.

Канонический контракт находится в `sitepack-spec/MAPPING.md`. Машиночитаемые
схемы:

- `semantic-profile.schema.json`;
- `mapping-recipe.schema.json`;
- `compatibility-report.schema.json`;
- обратно совместимая секция mapping в `capabilities.schema.json`;
- скомпилированный контракт в `transform-plan.schema.json`.
