# SitePack 1.0.0

SitePack 1.0 establishes the stable package contract for portable website backup and migration.

## Stable contracts

- explicit embedded, chunked, and external asset storage;
- stable external provider locators without credentials or temporary signed URLs;
- optional informational `sourceUrl` values that are never used instead of a registered provider locator;
- compact and full snapshot profiles;
- enrichment into a new package with a machine-readable report;
- portable source metadata and canonical entity types for future target recipes;
- matching PHP and Node reference validators.

## Breaking changes from development versions

- every asset must declare `storage`;
- profile aliases are removed;
- all core, envelope, object, and volume descriptors use `spec.version=1.0.0`;
- package readers must distinguish external dependencies from embedded files.

## Verification

Release verification requires schema parity, valid and invalid fixture suites in both validators, blob integrity checks, external locator security checks, and volume tests.
