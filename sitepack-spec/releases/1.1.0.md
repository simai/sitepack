# SitePack 1.1.0

SitePack 1.1.0 adds an optional detached Ed25519 signature contract while
keeping SitePack Core package manifests at `spec.version=1.0.0`.

Added:

- `schemas/signature.schema.json`;
- stable canonical signature input;
- external trust-store boundary;
- explicit `valid`, `untrusted` and `invalid` outcomes;
- PHP and Node signing and verification tools;
- deterministic, human-readable names for single-file and multi-volume
  snapshot distributions;
- zero-padded volume indexes and counts while retaining the canonical
  `sitepack.volumes.json` descriptor name.

Compatibility:

- unsigned SitePack 1.0 packages remain valid packages;
- applications may require a valid signature as a local import policy;
- the sidecar does not alter package bytes or package catalogs;
- importers continue accepting safe non-canonical filenames because package
  semantics come from the manifest, catalog, and Volume Set descriptor.
