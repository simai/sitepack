# SitePack 1.2.0

SitePack 1.2.0 adds portable semantic mapping and compatibility planning without
changing the package container or weakening SitePack 1.0/1.1 compatibility.

## Added

- semantic profile, mapping recipe, and compatibility report schemas;
- `sitepack.website-core@1.0.0` as the minimal portable website vocabulary;
- a legacy entity-type recipe instead of hidden aliases;
- mapping capabilities for target adapters;
- deterministic recipe compilation into a transform plan;
- explicit exact, transformed, fallback, skipped, and blocked outcomes;
- loss classification and trust rules for embedded or registry recipes.

## Compatibility

- SitePack 1.0 and 1.1 packages remain valid.
- Mapping artifacts are optional and unknown artifacts remain preservable.
- Existing capabilities documents without a `mapping` section remain valid.
- Concrete Bitrix, Larena, WordPress, and other platform recipes remain adapter
  artifacts rather than normative SitePack Core data.
